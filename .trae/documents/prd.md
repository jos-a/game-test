
## 1. Product Overview
类似小斗士的 2D 横版格斗游戏，支持单人对战和双人本地对战。
- 目的：提供经典的格斗游戏体验，支持键盘操作和多种角色选择
- 目标用户：喜欢格斗游戏的玩家，特别是对小斗士有怀旧情结的用户

## 2. Core Features

### 2.1 User Roles
无需用户角色区分，所有玩家均可使用全部功能。

### 2.2 Feature Module
1. **开始菜单页面**：角色选择、游戏模式选择、控制说明
2. **游戏主页面**：游戏画面、角色控制、碰撞检测、计分系统
3. **游戏结束页面**：胜负显示、重新开始选项

### 2.3 Page Details
| Page Name | Module Name | Feature description |
|-----------|-------------|---------------------|
| 开始菜单 | 角色选择 | 2-4个可选角色，每个角色有不同属性 |
| 开始菜单 | 模式选择 | 1v1 CPU 或 双人对战 |
| 游戏页面 | 角色移动 | 方向键控制移动、跳跃 |
| 游戏页面 | 攻击系统 | 普通攻击、特殊技能 |
| 游戏页面 | 血量系统 | 实时更新血量条 |
| 游戏页面 | 游戏结束 | 血量归零时判断胜负 |

## 3. Core Process
玩家进入游戏 → 选择角色和模式 → 开始战斗 → 决出胜负 → 重新开始或返回菜单

```mermaid
flowchart LR
  A["开始菜单"] --&gt; B["角色选择"]
  B --&gt; C["模式选择"]
  C --&gt; D["游戏进行中"]
  D --&gt; E{"决出胜负？"}
  E --&gt;|是| F["游戏结束"]
  F --&gt;|重新开始| D
  F --&gt;|返回菜单| A
```

## 4. User Interface Design
### 4.1 Design Style
- **主色调**：深色背景 (#1a1a2e)，霓虹亮色 (#e94560, #00d9ff)
- **按钮风格**：圆角矩形，带有发光效果，悬停放大动画
- **字体**：Press Start 2P (像素风格) + Roboto (辅助文字)
- **布局风格**：游戏画面居中，UI元素环绕
- **图标风格**：像素风格图标

### 4.2 Page Design Overview
| Page Name | Module Name | UI Elements |
|-----------|-------------|-------------|
| 开始菜单 | 主标题 | 像素风格字体，发光动画，居中显示 |
| 开始菜单 | 角色卡片 | 网格布局，悬停高亮，选中边框 |
| 游戏页面 | 游戏画布 | 居中显示，像素风格渲染 |
| 游戏页面 | 血量条 | 顶部左右两侧，渐变填充 |
| 游戏页面 | 控制提示 | 底部固定，半透明 |

### 4.3 Responsiveness
Desktop-first，游戏画布保持固定比例，UI元素自适应屏幕大小。

### 4.4 3D Scene Guidance
不适用 3D 场景。
